# 0.6.6 — первая публичная версия

- Пять героев с настоящими атаками: Windranger,Lina,Razor,Phantom Assassin,Dark Seer.
- Свободные Noto Sans и Cormorant SC с включёнными OFL-лицензиями.
- Настройка клавиш,профили,случайные последовательности,адаптивный темп,рекорды и локальный ладдер.
- Устранено изменение высоты арены при смене коротких/длинных названий клавиш с новой гарнитурой.

Проверено:354 проверки логики и управления,240 проверок размещения на четырёх размерах окна и пяти героях. Windows EXE и арена из экспортированного PCK запущены с Intel Arc A750/OpenGL3.3. На других компьютерах не проверялось. Часть headless-тестов при завершении выдаёт предупреждение2ObjectDB;ошибок проверок нет,в графическом запуске и EXE его нет.

Визуальные атаки объединяются на предельном вводе,при этом все правильные клавиши учитываются сразу. Игровые материалы Valve не становятся MIT-контентом;см.THIRD_PARTY_NOTICES.md.
