# Dota Combo Arena0.6.6

Распакуйте архив целиком и запустите DotaComboArena.exe. Файл DotaComboArena.pck должен находиться рядом. При первом запуске настройте бинды; выберите героя и начните разминку. Esc — пауза.

Код приложения открыт: https://github.com/chehlao1989-oss/DotaComboArena

Это неофициальный бесплатный фанатский тренажёр. Лицензии — LICENSE,THIRD_PARTY_NOTICES.md и вложенные OFL-файлы. Профили хранятся локально в %APPDATA%/Godot/app_userdata/Dota Combo Arena/.

В0.6.6 используются свободные NotoSans/CormorantSC. В остальном механика,сохранения и принятые атаки0.6.5 сохраняются. На предельном темпе визуальные атаки объединяются,каждая правильная клавиша учитывается сразу.
